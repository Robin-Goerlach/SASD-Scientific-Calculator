# Security Policy

**Status:** early source repository; no supported shipping app versions yet.

For vulnerabilities, avoid publishing exploitation instructions or sensitive personal data in a public issue. Contact the repository maintainer through a private GitHub security advisory/reporting channel **if enabled**. Otherwise use a non-public contact channel listed by the maintainer; none is asserted here.

Security considerations: hostile imported calculator programs, malformed state files, native FFI lifetimes, parsing limits, update integrity, and future third-party dependencies. This software currently runs a small offline local CLI and **does not** host a network API.

No formal support period or vulnerability response time is promised before a release exists.
