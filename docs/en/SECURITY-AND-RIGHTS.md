# Security, privacy, independent rights

## Minimal trust surface
- Calculations and local-state restoration remain offline; a permanent web server or cloud account is not part of the design.
- Treat imported programs, archives and state snapshots as untrusted input. Bound input sizes, parse deliberately, validate formats and avoid uncontrolled native code execution.
- Do not execute arbitrary OS shell commands or load untrusted native plug-ins from calculator programs.
- Future optional online features must be documented, separately permissioned and unavailable without consent where required.
- No ads or subscription SDKs in the M2 target; avoid telemetry unless justified and disclosed.

## Intellectual property
- MIT `LICENSE` covers original source in this repository; it does **not** grant rights to someone else's marks, designs, manuals, ROMs, operating systems, programs or images.
- Use SASD as product identity; do not reproduce historic manufacturer logos in the primary UI.
- Independently specify behavior, preserve provenance for test vectors and historic keyboard references.
- Only describe future historical compatibility factually, with evidence and separate review; a compatible claim must not imply affiliation or endorsement.
- Review all screenshot/mockup assets before app publication; generated mockups aren't proof of IP clearance.
- The owner must review final App Store legal/privacy requirements before release. This file is policy guidance, not legal advice.
