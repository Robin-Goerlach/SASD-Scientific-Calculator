# Generated concept artwork

These files illustrate a **possible** SASD Scientific Calculator UI. They are **not** screenshots of a functioning build and **not** an accurate historical keyboard specification.

- `ios-calculator-concept.svg` — calculator-only portrait iPhone concept.
- `desktop-workspace-concept.svg` — optional desktop calculator plus editor/stack/library.
- `science-icon-concept.svg` — sine/cosine on dark background.

High-resolution original PNG concepts remain in the local handoff package. The repository currently contains scalable SVG **redrawings** for visible previews; these are not pixel-identical copies of the last screenshot concepts. Before Apple App Store submission, replace all concept art with *actual screenshots of a tested build* where required and review final artwork rights.

Generated lettering, menu labels and key arrangements can be inaccurate. Verify each keyboard mapping independently.
