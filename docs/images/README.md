# Generated concept artwork

These files illustrate a **possible** SASD Scientific Calculator UI. They are **not** screenshots of a functioning build and **not** an accurate historical keyboard specification.

- `ios-calculator-concept.webp` — calculator-only portrait iPhone concept.
- `desktop-workspace-concept.webp` — optional desktop calculator plus editor/stack/library.
- `science-icon-concept.webp` — sine/cosine on dark background.

Original high-resolution images from the design conversation are included in the local handoff package; optimized WebP versions are used for README rendering. Before Apple App Store submission, replace all concept art with *actual screenshots of a tested build* where required and review final artwork rights.

Generated lettering, menu labels and key arrangements can be inaccurate. Verify each keyboard mapping independently.
